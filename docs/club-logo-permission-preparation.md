# 球団ロゴの許諾準備（2026-10-25、未送信）

[NPB12・MLB30球団の個別判断/窓口](visual-assets-rights.md) を維持。公式ロゴ採用0件、新規許諾なし。対象は公式ファイルのアプリ保存/再配信であり、球団名や客観的な事実を一律禁止する判断ではない。問い合わせ・フォーム入力・申請・契約は実施していない。

## 具体的な経路

- **DeNA**：[商標・肖像条件](https://www.baystars.co.jp/site/) の球団案内から用途を説明し適切な担当へ取次依頼。商品化連絡先は無料情報アプリの許諾窓口と未確認。事前申請条件は継続。
- **ソフトバンク**：[ライセンス事業](https://www.softbankhawks.co.jp/biz/service/license) の問い合わせ。相談→商談→基本契約などの手続きと地域/期間/料金の個別相談が掲載されるが、商品/販促向け制度の無料アプリ適用は要確認。スポンサー権・選手肖像は別条件。
- 他10球団は既存12球団表のproperty/licensing窓口。未確認の窓口は取次を確認する段階。パ・リーグ共同商品化制度も6球団アプリ包括許諾ではない。
- **MLB30球団**：[公式AboutのLicensing窓口](https://www.mlb.com/official-information/about-mlb) `Licensing_PublishingDepartment@mlb.com`。商品化向け窓口なので情報アプリ担当への取次、包括/個別許諾の範囲を確認する。サポートフォームは許諾そのものではない。MLB Currentデータの権限は拡張しない。
