# 月間レポート

`#/MLB/monthly` と `#/NPB/monthly`。既存の週間レポートと「もっと見る」から移動し、年度・月・公式戦/ポストシーズンを選べる。旧URLと保存データは変更しない。

- 月初〜月末を集計し、前月も暦月で比較する。2月・閏年・年境界をテスト。30日窓や年度別率の平均で代用しない。
- 既存の検証済み日程・結果・Historical Formのみ使用。DB/AI/新しいSource/APIなし。最大62日・同時4件、明示的なレポート表示時のみ取得。ホーム追加通信0。月別Formは最大2ファイル。
- MLB 2014〜2025は収録全範囲を検証できる公式戦の月に既存の月間母数条件を適用する。打者80打席、先発20回・既存先発数条件、救援8回・既存登板数条件。両月が揃う場合だけ前月比較。ポストシーズンの結果は別集計し、月間選手評価は保留する。
- NPB 2026は公式戦、CS First、CS Final、日本シリーズを分離する。既知の結果だけを集計し、失敗/欠損日を試合なしへ変換しない。HOT/Ranking Gateは閉じたまま。日本シリーズの個人成績・予告先発は補完しない。
- 一部収録の試合数や勝敗を全試合の結果とは扱わない。月境界の収録不足もpartial。収録最終日・利用条件・原記事revisionは維持する。

Rollback: UI/reader変更を通常revertする。immutable asset、canonical、個人ストアのmigrationはない。AIの試行履歴は触らず、追加月額費用¥0。
