## 日本語の方針

- NPBの表記は[個人年度別成績](https://npb.jp/bis/players/13115153.html)の「投打」「打撃成績」「所属球団」、[CS公式案内](https://npb.jp/games/2026/info_cs.html)の名称、[スポナビの公式案内](https://sports.yahoo.co.jp/promo/app/bblive/)の「試合」「投球・打撃データ」、[スポーツ紙のCS成績](https://www.nikkansports.com/baseball/professional/climax/2026/)等を参照。用語の確認のみで、これらの成績・記事本文・画像の新規取り込みは行わない。
- 「大会」を一律に置換しない。公式戦の条件エラー、CSの通算、シリーズ詳細、複数区分の選択で意味を分ける。元記事のタイトル・法的な出典文言は維持。
- MLBはレギュラーシーズン／ポストシーズンと固有のシリーズ名を維持し、CS・日本シリーズを流用しない。
- 投打の共通formatterは **throws → bats**。right/left/switch、MLBのR/L/B、確認済み日本語の右/左/両を表示へ写像。片方不明ならその側を未確認とし、順序を逆転・推測補完しない。

- 独自の編集対象を固定し、現在所属・予告先発・出場予定を示さない。写真は選考条件に含めない。既存の東2018年・牧2021年のCC BY-SA 4.0写真を再利用。写真のない正木・杉山も同じ情報設計で掲載。
- CSの有効なUUID／NPB ID／QIDと既存Canonical bridgeを使用。名前だけの照合なし。CSは各Gameのobservationがある行のみ使用。氏名の所属表記を現在のロスター証拠にしない。
- 公式戦は既存の静的Season JSONのみ。対象期間2026-03-27〜10-08、公開基準日10-12、196日中166日完了・25日試合なし・5日partial。未完了6試合の扱いは変更しない。
- CS元記事取得2026-10-18。Wikipediaの版111417089／111424439、著者・履歴・CC BY-SA 4.0・変更内容へのリンクを保持。独自解説は新規作成し、報道本文は転用しない。nf3は従来の保存済み公式戦表示のみで権利範囲を拡張しない。
- CS本文SHA256 `394e11d43baaf383c10f38e7a5de966bc021360af269682a1c4a20d5ed28aacd`。比較した公式戦本文SHA256 `f401d5e8d0740981c024f75273c1b191f162650d1c0fae9037b7e6827a150b81`。
- Homeの追加取得は既存の検証済みCS JSON **249,383 bytes / 1件**。1,522,419 bytesの公式戦JSONは「次戦への注目」または比較を開いた時だけ1回読み込み、特集内で共有。全年度の成績を初期JSへ含めない。Turso問い合わせ0・書き込み0。
- 既存のpin更新・Schema検証を通ったデータだけを読む。ステージ・試合・球団・観測・必要な数値や母数が一致しない対象は掲載せず、別人・欠損を推測しない。数値は再計算済みの収録値から表示し、率の単純平均・大会間合算なし。
- 優勝決定・有効な次戦予定なしでは次戦タブを表示しない。新pin採用時は4人の紹介理由の適合性を再確認。基準不一致なら掲載保留。自動的に別選手を捏造しない。

## この日のMVP（アプリ独自選出）

- 公式戦の日付別結果と試合詳細から開く。日付別の全終了試合が収録完了、試合ID／日付／球団／スコアが一致し、必要な選手成績が揃う場合のみ選出する。試合をスキップして日別MVPと称しない。
- 既に試合詳細で検証・保存した公開レスポンスを**端末のキャッシュからだけ**読む。最大12試合を上限とし、HTTP/DB取得なし。日付の索引は既存の静的公開JSON。キャッシュなし・欠損・訂正による不一致・収録未完了・未終了は選出保留。
- 1試合ずつの成績を比較する独自の目安：打者=安打+本塁打×3+打点、投手=アウト数÷3+奪三振÷2−失点×2。同点は併記。勝利貢献度や公式MVPを表す計算ではない。投手の回数を十進小数で扱わない。
- CSの日付別結果と各試合詳細には、部分収録のため選出保留を表示。日本シリーズの日程と各試合詳細には選手成績未収録を表示。**現在の公開データでCS・日本シリーズの日別MVPを選出した実績は0件**。成績がないことを出場なし・0成績にしない。
- 統計・出典・権利・CurrentのHOT/Rankingとは独立し、Gate解除・Facts保存・Roster更新・速報保証なし。

## 対象外・保全

対投手・得点圏・起用予定・守備走塁を含む評価、公式表彰、全選手を網羅したランキングは未対応。MLB Historicalへは同じ「観測→説明→独自評価」の考え方を応用できるが、このバッチでMLBに新たな表彰は実装しない。MLB2026 Currentの取得は0。Canonical DB監査はTurso制限のため未実施。Pixel接続なし、TalkBack実機NOT RUN。既存の署名差異の解決や署名キー操作は行わない。
